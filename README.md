# 🐑 牟牟工作台

一个**纯前端、零依赖、可离线**的牟牟专属工作台，七大模块全部独立展示，开页即见每日激励语，数据存在本地浏览器，不上传服务器。

| 模块 | 作用 |
| ---- | ---- |
| 📅 每日计划 | 待办清单、完成率进度条、切换日期、复制到明天 |
| 🧾 日常记账本 | 多元类目（含宠物/育儿）+ 支出账户 + 收入 + 本月收支结余 + SVG 类目饼图 |
| 💰 存款计划 | 银行卡/支付宝/微信/现金小金库 + 目标金额 + 总资产实时合计 |
| 📰 每日实时资讯 | 抖音热点 / 微博热点 / 鬼灭·二次元追踪板 / 每日60秒 + 收藏/复制 |
| 🎬 爆款视频 | ACG 谷子爆款拆解：爆点 + 可学习之处 |
| 📚 运营学习 | 抖音 / 小红书 / 播客 / 微博 运营干货收集 |
| ✍️ 每日复盘 | 工作生活总结 + 周度数据分析（7 模块汇总 + AI 洞察建议） |

## ✨ 功能要点

### 📅 每日计划
- 添加待办、勾选完成、编辑文本、删除。
- 顶部显示**今日完成率进度条**与 KPI 卡（已完成/总数/待完成）。
- 可切换日期查看历史，或把今天的待办一键复制到明天。

### 🧾 日常记账本（参考 iCost）
- 支出类目多元化：餐饮、交通、购物、居住、水电、医疗、娱乐、宠物、育儿、学习、人情、其他。
- 收入类目：工资、兼职、红包、理财、其他收入。
- 支出账户：银行卡 / 支付宝 / 微信 / 现金。
- 顶部实时显示「本月支出 / 本月收入 / 本月结余」。
- SVG 甜甜圈图展示本月支出类目占比。

### 💰 存款计划
- 按账户记录当前「小金库」余额。
- 可设目标金额与完成度进度条。
- **总资产实时合计**，输入余额时自动更新。

### 📰 每日实时资讯
- 抖音热点、微博热点（浏览器端公共接口）。
- 鬼灭咒术 / 二次元新品：手动追踪板，可复制新品链接与来源。
- 每日60秒：接入「60秒读懂世界」公共接口。
- 收藏、复制文案、一键复制全部收藏。

### 🤖 AI 智能输入
- 点击右下角机器人按钮，用大白话输入：
  - 「吃饭花了35微信」→ 自动记支出。
  - 「工资到账8000」→ 自动记收入。
  - 「明天9点跑步」→ 自动加明天待办。

### 📊 每日复盘 + 周度数据分析
- 按日期写每日工作生活总结。
- 底部「生成本周数据分析」按钮会弹出：
  - 本周计划完成率、收支结余、小金库总资产、爆款/学习收集数、复盘天数。
  - **AI 洞察与建议**（基于本地数据规则生成，无需联网）。

## 🔄 数据同步与备份

本工作台是**纯前端应用**，数据存于「当前浏览器」localStorage：

- ✅ 同一浏览器内自动持久化，刷新/关闭不丢。
- ✅ 设置里有「⬇️ 导出备份 / ⬆️ 导入备份」（JSON），可在电脑/平板/手机间搬运数据。

### ☁️ 云同步（手机 ↔ 电脑 互通，零额外服务器）

在「设置 → ☁️ 云同步」里开启，借用你自己的 **GitHub 私有 Gist** 做多端同步，**数据只存到你自己的私有仓库，不经过任何第三方服务器**：

1. 打开 GitHub → Settings → Developer settings → **Personal access tokens → Tokens (classic)** → Generate new token。
2. 点工作台「设置 → ☁️ 云同步」里的「🔗 一键去 GitHub 生成令牌」按钮，会**自动勾好 `gist` 权限**；点 Generate 复制令牌即可（不必自己找权限）。
3. 在工作台「设置 → ☁️ 云同步」里：粘贴令牌 → 点「① 创建同步空间」→ 出现「同步空间已就绪」。
4. 想互通的另一台设备（手机/电脑）用**同一个令牌 + 同一个同步空间**：粘贴令牌后，直接点「⬇️ 云→本机(拉取)」即可把数据拉过来。
5. 勾选「自动同步」后：打开应用自动从云端拉取，本机任何改动 1.5 秒后自动上传，两端始终保持一致（按 id 合并，两边同时加的数据都不会丢）。

> 令牌只保存在你本机浏览器，仅用于读写你自己的私有 Gist；如担心可随时在 GitHub 撤销该 token。
